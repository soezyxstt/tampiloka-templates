# Design kit Tampiloka

Skill `website-design-kit` adalah rujukan desain utama. Folder ini menyimpan aturan penerapan proyek, bukan salinan seluruh skill atau file Figma. Perubahan pada skill mengikuti proses pemeliharaan skill, terpisah dari perubahan template.

Sumber Figma: [Website Design Kit](https://www.figma.com/design/eXWI36xzNr8gtLBxFW0G6r/Design-Kit).

Mulai dari tugas pengunjung, isi yang tersedia, dan identitas brand. Pilih pola halaman dan bagian setelah itu. Warna serta font berasal dari brand. Layout commerce boleh berbeda nyata; alur staf harus tetap mudah dipelajari.

| Folder | Isi |
| --- | --- |
| `foundations` | Batas identitas brand, aksesibilitas, bahasa, dan token |
| `styles` | Empat komposisi commerce serta pilihan komponen |
| `sections` | Rujukan katalog, detail, dan pola transaksi |
| `patterns` | Alur checkout, staf, dan batas level fitur |

Seleksi visual serta hasil tinjau commerce berada di `templates/commerce/docs/design.md`. Jalankan capture desktop/mobile, uji keyboard dan reduced-motion, serta periksa alur nyata sebelum menandai sebuah preset siap.
