# Komposisi commerce

| ID | Susunan | Kapan sesuai |
| --- | --- | --- |
| `editorial` | Foto pembuka, narasi singkat, koleksi terbuka | Brand dengan foto dan cerita produk yang kuat |
| `market` | Kategori, pencarian, filter, grid padat | Katalog besar dan pembeli yang sudah tahu kebutuhannya |
| `atelier` | Galeri pilihan dengan ukuran media beragam | Koleksi kurasi, kriya, fashion, dan produk dengan detail visual |
| `compact` | Baris produk dan aksi beli cepat | Pembelian ulang atau katalog yang perlu dibandingkan cepat |

Pilihan kartu `open`, `framed`, `soft` serta tombol `solid`, `outline` tidak menentukan fitur. Warna contoh juga terpisah. Tetapkan brand pada `config/commerce.json`, lalu gunakan token bila brand memerlukan warna di luar contoh.
