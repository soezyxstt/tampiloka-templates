# @tampiloka/storage

Server-only adapters. `resolveDatabase(env)` returns a D1-style database. `DATABASE_PROVIDER` defaults to `d1` (native `DB` binding, or Cloudflare REST using `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_DATABASE_ID`, `CLOUDFLARE_API_TOKEN`). `turso` uses `TURSO_DATABASE_URL` and optional `TURSO_AUTH_TOKEN`; `postgresql` uses `DATABASE_URL`, `pg`, and a Node-compatible runtime. Turso and PostgreSQL batches are transactional; native D1 batches are transactional. PostgreSQL translates the documented worker subset: anonymous placeholders, INSERT OR IGNORE, instr, array json_each, simple dotted-path json_extract/json_set/json_insert/json, lower(hex(randomblob(16))) using PostgreSQL UUIDs, and the exact mutation_guards changes() statement immediately following a batch statement. JSON extraction returns text except known numeric paths photoVersion, sampleGalleryVersion, tick and unit. Other JSON types and paths require provider-specific SQL. PostgreSQL bigint and numeric results are converted to JavaScript numbers. Integers outside the JavaScript safe range and non-finite values throw; finite fractional values remain subject to JavaScript numeric precision limits. PostgreSQL migrations must supply equivalent constraints, triggers and rowid ordering columns; SQLite DDL is not automatically converted. Other SQLite functions and conflict forms are rejected where recognized; arbitrary SQL is not a complete SQLite parser. Avoid PostgreSQL JSON `?` operators and numbered SQLite parameters. PostgreSQL connection pooling requires a runtime that supports TCP and Node APIs; a shared pool per URL is limited to two connections with a 30-second idle timeout. Configure a managed pooler for serverless workloads.

`resolveObjectStorage(env)` accepts `OBJECT_STORAGE_PROVIDER=s3` with `S3_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, optional `S3_REGION` (default `auto`) and `S3_PUBLIC_URL`; or `uploadthing` with `UPLOADTHING_TOKEN`. `put(key, body, {contentType})`, `get(key)` and `delete(key)` run on the server. UploadThing assigns its own key; persist the returned key. `get` buffers the object; enforce upload and download size limits in the caller. Authorize every operation in the application and never expose credentials. Use a private S3 bucket and omit S3_PUBLIC_URL for private media. UploadThing uploads request private ACL and require per-request ACL overrides enabled in the UploadThing dashboard; privateUploads is true and put returns only the opaque key. A public URL does not itself enforce access control.

`runMigrations(db, [{id, statements: [sql, ...]}])` tracks IDs and atomically applies each migration. Supply explicit statements and provider-specific migrations; no automatic SQLite conversion is attempted. Run once before serving traffic and serialize concurrent deploys externally. D1 REST is subject to Cloudflare API limits. The adapters do not provision resources or migrate existing data.

`createPostgresDatabase(pool)` accepts a pg-compatible pool (async `connect()`, client `query()` and `release()`) and uses the same translation, transactions and error propagation as the production resolver. It is useful for in-process integration tests; it does not change provider credential validation.
